# 개발 시작하기

처음에는 작은 장면 하나를 만들어 실행과 수정 과정을 익혀 보세요. 개발 질문은 [Q&A](https://github.com/sickBoyStudio/.github/discussions/categories/q-a)에 남길 수 있습니다.

## 준비

[Roblox Studio](https://create.roblox.com)를 설치하고 계정에 2단계 인증을 설정합니다. 팀 작업에 참여한다면 GitHub 계정도 준비합니다. 실제 사용자 데이터와 개발 테스트용 환경을 구분합니다.

## 첫 작업

빈 프로젝트에서 파트 하나를 만들고 위치·크기·재질을 바꿔 봅니다. Play로 확인한 뒤 서버 스크립트와 로컬 스크립트가 각각 실행되는 위치를 익힙니다. 이어서 입력 처리, 서버 검증과 데이터 저장을 학습합니다.

Studio에서 데이터 저장을 시험할 때 운영 데이터에 접근하지 않도록 별도 테스트 프로젝트와 데이터를 사용합니다. 수익화보다 오류 처리와 저장·복구 확인을 먼저 합니다.

## 협업

작은 변경부터 브랜치와 PR로 제출합니다. Team Create 작업도 검토할 수 있도록 변경 목적, 관련 에셋과 검증 결과를 연결합니다. 수익 배분 참여는 [참여 안내](../CONTRIBUTING.md)의 사전 합의 절차를 따릅니다.
