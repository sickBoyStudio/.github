# 기여자 장부 리뷰 기준

검사기 통과는 아래 검토를 대신하지 않습니다. 민감한 증빙은 제한된 공간에서 확인하고 PR에는 관리 번호만 연결합니다.

## 모든 변경

- PR 작성자와 실제 당사자가 누구인지 확인했는가?
- 적용 정책·약정의 고정 버전과 변경 근거가 연결돼 있는가?
- 대상 게임·비율·합계·상한과 적용일이 맞는가?
- 이전 이력을 보존하고 새로운 정정·변경 이력을 추가했는가?
- 다른 기여자의 권리나 지급 설정에 영향을 주는가?

## 첫 등록

작업 사전 합의, 실제 기여·검수, 본인과 오너 확인, 첫 5%, 상한 여유, 지급 시작일과 계정 확인을 대조합니다. 일반 PR 병합만으로 수익 약정 동의가 끝났다고 판단하지 않습니다.

## 상향·하향·상태 변경

상향 근거와 적용일을 확인합니다. 하향·박탈은 경고가 없더라도 적용 약정의 소명·동의·분쟁 절차를 직접 확인합니다. `left`나 `inactive` 변경만으로 비율이 자동 줄어들지 않습니다. 분쟁 중인 권리를 자동 검사 결과로 확정하지 않습니다.

## 자동 검사의 범위

파일 구조, 수치·상한, 작성자별 변경 범위, 이전 장부 읽기, 중복 키와 기존 기록 보존을 확인합니다. 이전 장부가 없거나 잘못되면 비교 검사는 실패해야 합니다.

검사기는 서명·신원·법적 효력·외부 계정 소유·실제 지급·권리자 허락을 확인하지 않습니다. 저장소 관리자가 검사 자체를 수정하거나 우회하는 것도 이 도구만으로 방지하지 못합니다. 실제 리뷰와 지원되는 브랜치 보호·권한 관리가 필요합니다.
