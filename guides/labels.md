# 🏷️ 라벨 도감

유형 1개, 분야 0~2개, 필요한 상태 1개면 충분해요. 이모지는 설명에, 검색하기 쉬운 이름은 라벨에 담았습니다.

| 라벨 | 뜻 | 적용 범위 |
| --- | --- | --- |
| `bug` | 🐛 예상과 다르게 움직여요 — 재현 방법을 함께 남겨 주세요 | 공통 |
| `enhancement` | ✨ 게임을 한 단계 더 재미있고 편하게 만드는 개선 | 공통 |
| `documentation` | 📚 설명서·가이드·크레딧을 더 읽기 쉽게 | 공통 |
| `question` | 🙋 막힌 부분을 함께 풀어요 — 해결되면 답을 남겨 주세요 | 공통 |
| `good first issue` | 🌱 첫 기여 환영 — 범위와 완료 기준이 분명한 작은 작업 | 공통 |
| `help wanted` | 🙌 동료의 손길이 필요한 작업 | 공통 |
| `accessibility` | ♿ 더 많은 사람이 편하게 플레이할 수 있도록 | 공통 |
| `duplicate` | 🔗 이미 있는 이야기 — 원본 이슈 링크로 이어 주세요 | 공통 |
| `invalid` | 🧩 이 저장소에서 다루기 어려움 — 이유와 적절한 경로 안내 | 공통 |
| `wontfix` | 🗃️ 지금은 진행하지 않음 — 결정 이유를 기록해 주세요 | 공통 |
| `참여 신청` | 🤝 프로젝트에 함께하고 싶어요 | 공통 |
| `사용 허가` | 🔑 코드·에셋을 사용하기 전 허가와 조건 확인 | 공통 |
| `작업` | 🛠️ 맡을 범위와 완료 기준이 정해진 제작 작업 | 공통 |
| `플레이테스트` | 🎮 직접 해보고 재미·조작감·문제를 기록해요 | 공통 |
| `연락 경로` | 📮 민감한 내용 없이 비공개 연락 방법만 요청 | 공통 |
| `분야: 스크립트` | Luau·서버·클라이언트·게임 시스템 | 공통 |
| `분야: 맵·조명` | 공간·레벨 디자인·라이팅 | 공통 |
| `분야: 모델·애니메이션` | 3D 에셋·리깅·움직임 | 공통 |
| `분야: UI·UX` | 화면 구성·입력·사용 흐름 | 공통 |
| `분야: 사운드` | 음악·효과음·공간 음향 | 공통 |
| `분야: 기획·밸런스` | 게임 규칙·난이도·플레이 경험 | 공통 |
| `분야: QA` | 재현·기기 호환성·성능 확인 | 공통 |
| `분야: Git·도구` | Git·Rojo·빌드·제작 도구 | 공통 |
| `상태: 확인 필요` | 아직 재현·범위·담당 확인이 필요해요 | 공통 |
| `상태: 진행 중` | 담당자가 작업 중이에요 | 공통 |
| `상태: 리뷰 요청` | 작업을 확인하고 의견을 주세요 | 공통 |
| `상태: 도움 필요` | 진행을 막는 문제가 있어요 — 필요한 도움을 본문에 기록 | 공통 |
| `소통: 공지` | 새 소식과 확인할 일정 | 커뮤니티 |
| `소통: 라운지` | 자기소개·잡담·아이디어·자료 공유 | 커뮤니티 |
| `소통: 작품 자랑` | 완성작도 작업 중인 화면도 환영 | 커뮤니티 |
| `소통: 팀원 모집` | 함께 만들 사람·참여할 프로젝트 찾기 | 커뮤니티 |

라벨은 분류 도구이며 업무 배정·우선순위·보상을 확정하지 않습니다. 자세한 사용 예시는 [GitHub 플레이북](github-playbook.md)을 보세요.
