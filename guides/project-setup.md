# 프로젝트 개설

1. 오너와 실제 계약·지급 책임자를 정하고 공개 범위를 선택합니다.
2. `templates/README.md`, `PROJECT_BRIEF.md`, `CREDITS.md`를 복사해 채웁니다. 수익 배분 프로젝트에는 `CONTRIBUTORS.yml`과 `WORK_AGREEMENT.md`도 준비합니다.
3. 코드·에셋의 권리 관계에 맞는 라이선스를 선택합니다. `templates/LICENSE`는 독점 프로젝트용 예시입니다. 제3자 라이선스를 덮어쓰지 않습니다.
4. 메인테이너와 리뷰 담당자를 정하고 필요한 권한만 부여합니다. 보호 규칙 지원 여부는 저장소 설정에서 확인합니다.
5. 보안 신고, 버그 신고, 실행·검증 절차를 안내합니다. 공통 양식을 사용하더라도 프로젝트 고유의 문의 경로와 지원 범위를 확인합니다.
6. 작업 착수 전에 사전 합의와 적용 버전을 확인합니다. 보호자·지급 자료를 공개 저장소에 넣지 않습니다.
7. 출시 전 [출시 확인](../templates/RELEASE_CHECKLIST.md)을 완료합니다.

기여자 검사 워크플로를 복사할 때 검토한 공통 워크플로의 커밋을 고정합니다. 도구 갱신과 정책 적용은 별개로 승인합니다. 검사기는 형식과 비율을 검증하며 계약·실제 지급까지 검증하지 않습니다.
