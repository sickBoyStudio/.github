# 작업 사전 합의

> 작성 양식입니다. 당사자 확인과 명시적 동의 전에는 확정 약정으로 사용하지 않습니다. 계약 신원·연락처·보호자 확인 자료는 접근이 제한된 별도 공간에 보관합니다.

- 프로젝트와 대상 작업:
- 당사자 계정 / 비공개 신원 확인 기록 ID:
- 적용 정책 버전과 고정 커밋 링크:
- 작업물·포함 범위·제외 범위:
- 납품 일정 / 검수 기준 / 보완·재검수 방법:
- 수익 배분 대상 여부 / 첫 인정 5% / 상한 여유 확인:
- 등록 조건 / 적용일 / 지급 계정 확인 기록:
- 이전 보유 자료·제3자 자료와 허가 근거:
- 이용허락 범위·기간 / 수정·홍보·플랫폼 이식 포함 여부:
- 프로젝트 밖 재사용·양도·재허락 조건:
- 크레딧 표기:
- 취소·중단·지연 시 이미 수행한 작업과 보상 처리:
- 필요한 법정대리인 동의 확인 기록 ID:
- 오너 확인 / 기여자 확인 / 확인 날짜:

동의는 최종 문서 버전과 연결해 양측이 명시적으로 남깁니다. 미응답·이모지·초대 수락은 동의로 간주하지 않습니다.
