# 프로젝트 이름

프로젝트가 무엇을 하는지 한두 문장으로 적습니다.

| 항목 | 내용 |
| :--- | :--- |
| 상태 | 기획 / 개발 / 테스트 / 운영 / 종료 중 선택 |
| 오너·메인테이너 | 담당 GitHub 계정 |
| 실행 환경 | Studio 및 사용 도구 버전 |
| 문의·보안 | 실제 확인한 문의 경로와 비공개 신고 경로 |
| 라이선스 | 코드·에셋별 적용 문서 |

## 실행과 검증

설치, 테스트 프로젝트 설정, 실행 순서와 확인 방법을 적습니다. 운영 키나 실제 사용자 데이터를 포함하지 않습니다.

## 작업과 참여

현재 범위, 제외 범위와 참여 절차를 적습니다. 수익 배분 프로젝트라면 작업 전에 합의할 항목과 적용 정책의 고정 링크를 명시합니다.

## 출시와 기록

릴리스·변경 기록·되돌리는 방법과 크레딧 문서의 실제 위치를 연결합니다.
