# 출시 확인

- 프로젝트 / 버전 / 승인자 / 출시 예정일:
- [ ] 주요 동작, 오류 처리와 데이터 저장·복구를 확인했다.
- [ ] 서버에서 권한·구매·재화 변경을 검증했다.
- [ ] 키·쿠키·개인정보·테스트 데이터 노출을 확인했다.
- [ ] 코드·폰트·음악·이미지·모델의 이용 조건과 크레딧을 확인했다.
- [ ] 수익화·콘텐츠·공개 설정은 현재 플랫폼 요건을 확인했다.
- [ ] 적용 정책·기여자 비율·지급 시작일과 실제 설정을 대조했다.
- [ ] 개인정보 처리와 문의·보안 신고 경로를 확인했다.
- [ ] 백업·되돌리는 방법·장애 담당자를 정했다.
- [ ] 알려진 문제와 출시 후 확인 항목을 기록했다.

해당하지 않는 항목은 이유를 적습니다. 체크만 하지 말고 검증 기록을 연결합니다.
