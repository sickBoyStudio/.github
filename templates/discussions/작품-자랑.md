# [작품] 글쓰기 양식

아래 내용을 복사해 해당 카테고리의 새 글에 붙여 넣으세요.

🎮 문 하나, 발소리 하나, 10초짜리 테스트도 작품입니다. 오늘 만든 걸 보여 주세요! 작은 작업도 환영합니다. 공개해도 되는 내용만 올려 주세요. 미공개 코드·개인 연락처·정산 자료는 프로젝트의 비공개 경로에서 다룹니다.

## 어떤 작업인가요?

예: 불이 꺼질 때만 움직이는 NPC 프로토타입

## 현재 단계

아이디어·콘셉트 / 제작 중 / WIP / 프로토타입 / 플레이테스트 / 완성·업데이트

## 화면·영상·플레이 링크

이미지를 끌어다 놓거나 공개 가능한 링크를 붙여 주세요. 콘셉트와 실제 구현을 구분해 주세요.

## 어떤 부분을 만들었나요?

내가 맡은 부분 / 재미있었던 구현 / 아직 작업 중인 부분

## 어떤 반응을 원하나요?

가볍게 구경하고 응원해 주세요 / 특정 부분의 피드백이 필요해요 / 플레이테스트를 부탁해요

## 특히 봐주면 좋은 부분

예: 모바일에서 버튼이 잘 보이나요? 첫 번째 퍼즐의 힌트가 충분한가요?
