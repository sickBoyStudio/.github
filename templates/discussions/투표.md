# 🗳️ 투표 작성 예시

GitHub의 투표 카테고리는 자동 입력 양식을 지원하지 않습니다. 새 투표의 본문에 아래 내용을 복사하고 선택지는 GitHub의 Poll 옵션에 입력하세요.

## 무엇을 정하나요?
<!-- 한 번에 한 가지 결정. 예: 다음 플레이테스트에서 먼저 확인할 구간 -->

## 배경과 선택 기준
<!-- 왜 지금 결정하는지, 각 선택지의 장단점 -->

## 투표 종료
<!-- YYYY-MM-DD HH:mm KST. 결과를 누가 어디에 정리할지도 적습니다. -->

## 결과를 어떻게 사용하나요?
<!-- 참고 의견인지, 실제 결정에 반영할지. 조직 정책 변경은 기존 운영 규칙의 절차를 따릅니다. -->

선택지 예시: 튜토리얼 / 첫 번째 협동 구간 / 모바일 조작 / 기타(댓글)

마감 뒤에는 이 글을 수정해 결과·결정 이유·후속 작업 링크를 남겨 주세요. GitHub에서 투표가 자동 종료된다고 가정하지 말고 종료 사실을 본문에 표시합니다.
