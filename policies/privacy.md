# 개인정보와 기록 관리

> v1.1 개정안 · 미시행. 공지·승인과 시행일 확정 후 적용합니다. 기존 합의는 당사자의 별도 동의 없이 변경하지 않습니다.

## 최소 수집

커뮤니티 참여에는 GitHub 닉네임과 작업 관련 정보만 사용합니다. 실제 계약·지급에 추가 정보가 필요한 경우 담당자, 목적, 수집 항목, 접근자와 보관 기간을 먼저 안내합니다. 신분증·주민등록번호를 일반 이슈나 PR로 수집하지 않습니다.

## 접근과 보관

공개 자료에는 개인정보가 없는 작업 요약과 결정만 남깁니다. 계약·정산·신고 원본은 필요한 담당자만 접근하는 별도 공간에 보관합니다. 비공개 저장소라는 이유만으로 개인정보 보관에 충분하다고 보지 않습니다.

담당자는 분기마다 보관 필요성을 검토합니다. 목적이 끝나면 삭제하거나 익명화하되, 법정 보존 또는 진행 중인 분쟁에 필요한 자료는 근거·범위·재검토일을 기록하고 접근을 제한합니다. 모든 자료를 무기한 보관하지 않습니다.

## 수정·삭제 요청

[지원 안내](../SUPPORT.md)로 요청합니다. Git 이력, 포크, 캐시와 외부 복제본 때문에 원본 수정만으로 모든 사본이 사라지지는 않습니다. 담당자는 처리 가능한 범위와 남는 기록, 추가 조치를 안내합니다. 노출된 키는 삭제 요청과 별개로 즉시 폐기합니다.

## 사진과 작업물

갤러리에 올리기 전에 촬영자·제작자의 권리와 등장 인물의 공개 동의를 확인합니다. 위치·연락처·학교 등 불필요한 정보와 이미지 메타데이터를 확인합니다. 공개 동의 범위가 바뀌면 게시 유지 여부를 재검토합니다.

이 문서는 협업 공간의 기록 관리 기준입니다. 게임 이용자 데이터를 수집하는 경우 프로젝트별 실제 처리 내역에 맞는 별도 안내가 필요합니다.
