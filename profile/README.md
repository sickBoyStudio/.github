만들고 있는 게임, 풀리지 않는 코드, 문득 떠오른 아이디어를 나눕니다. 완성된 작업이 아니어도 좋습니다. 구경하다 관심 가는 이야기에 댓글부터 남겨 주세요.

## 처음 왔다면

가입이나 프로젝트 참여를 먼저 결정할 필요는 없습니다. 관심 있는 곳부터 둘러보세요.

| 하고 싶은 것 | 여기서 시작하세요 |
| :--- | :--- |
| 가볍게 인사하거나 이야기 나누기 | [자기소개·자유](https://github.com/sickBoyStudio/.github/discussions/categories/자기소개-자유) |
| 개발하다 막힌 부분 질문하기 | [Q&A](https://github.com/sickBoyStudio/.github/discussions/categories/q-a) — 하려던 것과 막힌 부분을 적어 주세요. |
| 만들고 있는 것 보여 주기 | [작품 자랑](https://github.com/sickBoyStudio/.github/discussions/categories/작품-자랑) — 진행 중인 작업과 짧은 테스트도 좋습니다. |
| 프로젝트에 참여하거나 팀원 찾기 | [팀원 모집](https://github.com/sickBoyStudio/.github/discussions/categories/팀원-모집) — 관심 분야와 가능한 작업 범위부터 이야기해 주세요. |

GitHub가 익숙하지 않다면 **Discussions는 게시판**, **Issues는 작업·문제 접수**, **PR은 변경 검토 요청**으로 생각하면 됩니다. 글을 쓰려면 GitHub 로그인이 필요합니다.

## 프로젝트에 참여하려면

**모집 글 확인 → 담당자와 역할·범위 이야기 → 참여 절차 확인 → 작업 시작** 순서로 진행합니다.

질문이나 피드백을 남기는 것과 프로젝트의 정식 기여자가 되는 것은 구분합니다. 보상을 전제로 작업한다면 시작 전에 인정 조건, 수익 배분과 작업물 사용 범위를 담당자와 확인해 주세요. 자세한 등록 절차는 [참여 안내](https://github.com/sickBoyStudio/.github/blob/main/CONTRIBUTING.md)에 있습니다.

## 편하게 지내기 위한 약속

- 의견이 달라도 사람을 깎아내리지 않고 작업에 대해 이야기합니다.
- 다른 사람의 코드와 이미지를 사용할 때는 출처와 허가 조건을 확인합니다.
- 개인정보와 비공개 작업물은 공개 글에 올리지 않습니다.
- 역할·일정·보상처럼 서로 기대하는 내용은 글로 남겨 확인합니다.
