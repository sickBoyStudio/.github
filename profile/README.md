어떤 게임을 만들고 싶은가요? 마음에 드는 프로젝트를 둘러보고, 직접 해보고 싶은 부분을 이야기해 주세요. 코드 한 기능, 맵의 한 공간, 소리 하나부터 시작할 수 있습니다.

아직 참여할 프로젝트를 정하지 않았다면 작업을 구경하거나 개발 이야기를 나눠도 좋습니다.

## 내 취향의 프로젝트 찾기

[NOLL](https://github.com/orgs/sickBoyStudio/discussions/6) · [Christmas in Seoul](https://github.com/orgs/sickBoyStudio/discussions/7) · [Christmas in Hell](https://github.com/orgs/sickBoyStudio/discussions/8)

세 프로젝트의 **공개 소개**에서 게임의 방향·현재 단계·참여할 수 있는 범위를 먼저 확인하세요.

[팀원 모집 보기](https://github.com/sickBoyStudio/.github/discussions/categories/recruiting)

프로젝트의 **장르·플레이 방식 → 실제 화면과 소개 → 진행 상황 → 참여할 작업** 순서로 살펴보세요. 관심 가는 부분이 있다면 “이 작업을 맡아보고 싶어요”라고 남겨 주세요. 참여 조건은 담당자와 이야기한 뒤 결정하면 됩니다.

비공개 저장소는 권한이 있는 사람에게만 보입니다. 처음 방문했다면 공개된 팀원 모집 게시판에서 시작할 수 있습니다.

## 처음 왔다면

가입이나 프로젝트 참여를 먼저 결정할 필요는 없습니다. 관심 있는 곳부터 둘러보세요.

**[👋 처음 온 분 안내](https://github.com/orgs/sickBoyStudio/discussions/1) · [🌱 공개 첫 작업 고르기](https://github.com/sickBoyStudio/.github/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22good%20first%20issue%22)**

용어를 쉬운 말로 풀기, Studio 첫걸음 따라 하기, 모바일 글쓰기 점검부터 시작할 수 있습니다. 게임 저장소 초대 없이도 참여할 수 있어요.

| 하고 싶은 것 | 여기서 시작하세요 |
| :--- | :--- |
| 가볍게 인사하거나 이야기 나누기 | [자기소개·자유](https://github.com/sickBoyStudio/.github/discussions/categories/lounge) |
| 개발하다 막힌 부분 질문하기 | [Q&A](https://github.com/sickBoyStudio/.github/discussions/categories/q-a) — 하려던 것과 막힌 부분을 적어 주세요. |
| 만들고 있는 것 보여 주기 | [작품 자랑](https://github.com/sickBoyStudio/.github/discussions/categories/showcase) — 진행 중인 작업과 짧은 테스트도 좋습니다. |
| 프로젝트에 참여하거나 팀원 찾기 | [팀원 모집](https://github.com/sickBoyStudio/.github/discussions/categories/recruiting) — 관심 분야와 가능한 작업 범위부터 이야기해 주세요. |

GitHub가 익숙하지 않다면 **Discussions는 게시판**, **Issues는 작업·문제 접수**, **PR은 변경 검토 요청**으로 생각하면 됩니다. 글을 쓰려면 GitHub 로그인이 필요합니다.

## 프로젝트에 참여하려면

**모집 글 확인 → 담당자와 역할·범위 이야기 → 참여 절차 확인 → 작업 시작** 순서로 진행합니다.

질문이나 피드백을 남기는 것과 프로젝트의 정식 기여자가 되는 것은 구분합니다. 보상을 전제로 작업한다면 시작 전에 인정 조건, 수익 배분과 작업물 사용 범위를 담당자와 확인해 주세요. 자세한 등록 절차는 [참여 안내](https://github.com/sickBoyStudio/.github/blob/main/CONTRIBUTING.md)에 있습니다.

## 프로젝트를 소개하는 분께

프로젝트마다 **장르·유형 태그와 한 줄 설명**을 붙여 주세요. 스토리가 있다면 README에 배경을 소개하고, 현재 화면·진행 상황·다른 개발자가 맡아볼 작업도 함께 적어 주세요.

[소개 작성 안내](https://github.com/sickBoyStudio/.github/blob/main/guides/project-presentation.md) · [README 양식](https://github.com/sickBoyStudio/.github/blob/main/templates/README.md)

## 편하게 지내기 위한 약속

- 의견이 달라도 사람을 깎아내리지 않고 작업에 대해 이야기합니다.
- 다른 사람의 코드와 이미지를 사용할 때는 출처와 허가 조건을 확인합니다.
- 개인정보와 비공개 작업물은 공개 글에 올리지 않습니다.
- 역할·일정·보상처럼 서로 기대하는 내용은 글로 남겨 확인합니다.
